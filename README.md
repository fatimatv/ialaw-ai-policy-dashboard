# IALAW AI Policy Dashboard

Dashboard interactivo para comparar politicas institucionales peruanas de uso etico, seguro y responsable de inteligencia artificial.

## Estructura

- `index.html`: aplicacion estatica autocontenida.
- `public/ialaw-assets/`: logos oficiales de IALAW usados por el dashboard.
- `vercel.json`: configuracion basica para Vercel.

## Marca

Aplica el brandbook de IALAW: azul `#011EF4`, amarillo `#FBBB02`, grises institucionales y logo oficial. Usa Poppins como sustituta web operativa de Cocogoose/Bebas Neue.
